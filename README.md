# Data Jobs: Salary & Skills Analysis

## 📌 Project Overview

This project explores the relationship between job roles, salary distributions, and in-demand technical skills in the data analytics and data engineering industry.

Using Microsoft Excel, I analyzed salary trends across different data-related job positions and examined which technical skills are most frequently associated with specific roles.

The objective is to understand the skills employers demand, how salaries vary across job roles, and how technical skills relate to compensation.

## 🎯 Project Objectives

- Analyze salary differences across various data-related job roles.
- Compare median salaries in the US and outside the US.
- Identify the most in-demand technical skills for Data Engineers.
- Analyze the relationship between technical skills and median salaries.
- Compare the number of skills required across different job positions.
- Use Excel PivotTables and charts to summarize and visualize findings.

- Data Engineer
